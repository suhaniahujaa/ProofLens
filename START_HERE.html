This is a website that runs on your computer. You start the Python worker, then use the app in your browser.

Already have the older project?

  1. Stop the app with Ctrl+C. Keep that terminal window open.
  2. Extract the new ZIP separately.
  3. Copy the new ProofLens folder’s contents into your existing folder containing start.py. Choose Replace files.
  4. Keep your existing data folder, .env file and .venv folder. Do not delete your old project folder. The new ZIP does not include these private files.
  5. Start it again with the command below. Press Ctrl+F5 in the browser to load the new screen.

1. Start the app

Open the extracted folder containing start.py in VS Code. Open its terminal and run:

py -3.12 start.py

Or double-click START_WINDOWS.bat. Use your installed Python 3.12. The first start installs the libraries and needs internet. Keep the terminal running while using the site.

If the browser does not open, enter http://127.0.0.1:8000. On macOS/Linux, run python3 start.py.

2. Connect the AI

  1. Open Settings inside the app.
  2. Paste your own API key into the password box. Click Save connection.
  3. Click Test saved connection. Read its result. This checks text and meaning search; it can use a small amount of API credit.

Your API account needs available API credits. ChatGPT access and API billing are separate. Do not send your key in a message or screenshot. Saving it here updates the app immediately; no restart is needed.

3. Try this easy example

Open Evidence sources → Write a note.

Title: MCA admission checklist

For MCA admission, students must bring their original marksheets, two passport photographs and a government photo identity card.

Click Save note. Open Ask your library and ask:

What documents should I bring for MCA admission?

The app finds your saved words and asks the AI to answer from them. The source under the answer shows the exact passage. This describes your saved note; it does not prove that a real university issued it.

4. Check a real forwarded message

  1. Open Evidence sources → Website. Approve the real issuing organization’s domain.
  2. Import its actual notice page or readable PDF. Add the publication date printed on the notice if needed.
  3. Open Check a message. Choose My workspace at the top.
  4. Paste the message. Add the organization and original message date when needed.
  5. Click Find the evidence, then read the quotes and original links.

Only a page fetched from an approved website can establish an official announcement in this version. Your uploaded files and personal notes remain useful in Ask your library.

5. Close it and return

Your saved notes, sources, document text, reports and library answers remain in the project’s data folder. Close the browser, reopen the same address, and they will still be there. If you stopped the terminal too, run the start command again.

Your drafts and menu preferences are saved in the same browser. Keep data and .env when updating the project. Clearing browser data removes browser drafts, while saved documents remain in the project folder.

The menu

Use the × in the sidebar to close it. Use the menu button at the top left to open it again. Slide or click the text/screenshot/voice and website/upload/note options. The phone layout also has bottom navigation.

If something goes wrong

  • AI error: open Settings and run the connection test. The updated app shows the specific error; it does not make up a verdict.
  • Not enough evidence: add the exact relevant document and check names/dates. Missing proof does not mean false.
  • Saved sources look missing: select My workspace and use your existing project folder.
  • Python 3.15 or Rust error: use py -3.12 start.py. The updated starter checks and replaces an incompatible virtual environment.
